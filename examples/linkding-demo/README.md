# Linkding demo docs

This page exists to show the fibcheck GitHub Action on a pull request. It describes Linkding 1.47.0, which the Action starts in Docker on GitHub's runner. When a pull request changes this page, fibcheck checks it in a real browser with Kane CLI and posts the result on the pull request.

To open the Admin app, go to the *Settings* view and click on the *Admin* tab. This opens the *Site administration* page.

To rename a tag, open the *Tags* page, select *Edit* in the tag's row, update the *Name*, and select *Save*.
